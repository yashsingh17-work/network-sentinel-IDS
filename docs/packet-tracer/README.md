# Packet Tracer lab

Use [`TOPOLOGY.md`](TOPOLOGY.md) as the single source of truth for this project’s
Packet Tracer network. It defines the exact R1, switches, hosts, ports, IP
addresses, routing, SPAN session, services, and safe test flows from the active
`simulation interface.pkt` lab.

The former alternative enterprise showcase topology was removed because its
addresses and devices did not match this working lab. For how this simulated
lab reaches the local IDS dashboard, read [`IDS_BRIDGE.md`](IDS_BRIDGE.md).
